the why

why i built it

When I have several Claude Code sessions going at once, it's hard to tell at a glance which ones are still working, which are done, and which are stuck waiting on me. A list of sessions doesn't make that obvious, and a session waiting for my answer can sit there for a long time before I notice. I wanted a more fun way to keep track of them: a little dungeon where every session is a character.

02

how it works

the guts

The game is a Godot 4.7 (.NET) project in C#. It reads the Claude desktop app's session list and transcripts on the same computer, with no setup needed, and gives every Claude Code session its own character in a top-down, PSX-style dungeon. A session keeps the same character from run to run.

  • A status line on each character: Working, Needs you, Done or Resting, plus the step it's on right now (for example "Running tests" or "Editing Main.cs"), read from the end of its transcript.
  • Body language matches state: working agents walk around with a lit torch, and agents waiting on me are struck down with a red marker. A banner counts them ("2 AGENTS AWAITING YOU").
  • Talk to them: walking up to a character and pressing E shows what it did and what it needs, T opens that session in Claude, and "send away" hides a session.

Key decisions

  • The theme does the work: the world mirrors the agents' state, so a dungeon full of struck-down characters means I have answers to give, without reading a single list.
  • No setup: it reads the session data Claude already keeps instead of asking me to register projects.
  • Make it yours: characters are just image files in a portraits/ folder, and status wording, the map and the PSX look each live in their own place, so the game can be reskinned.
  • Safe to try: a dry-run mode makes every action that would launch or message Claude print what it would do instead.
  • An optional project layer: extra features for one numbered-project workflow (a dashboard, test checklists and handoffs) are off by default, so the base game stays simple.
